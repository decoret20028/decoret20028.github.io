## Условие
Ферзь ходит по диагонали, горизонтали и вертикали. Даны две
различные клетки доски 8×8. Нужно определить, может ли ферзь
попасть из первой во вторую за один ход (YES / NO).

## Идея
Пусть `dx = x1 - x2`, `dy = y1 - y2`. Ферзь бьёт клетку, если:
- `x1 == x2` — вертикаль;
- `y1 == y2` — горизонталь;
- `|dx| == |dy|` — диагональ. Чтобы не писать модуль,
  сравниваем квадраты: `dx*dx == dy*dy`.

## Решение (C++11)
```cpp
#include <iostream>
using namespace std;

int main() {
    int x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;

    int dx = x1 - x2;
    int dy = y1 - y2;

    if (x1 == x2 || y1 == y2 || dx * dx == dy * dy) {
        cout << "YES";
    } else {
        cout << "NO";
    }
    return 0;
}
```

## Вывод
Задача решается одним условным оператором за O(1)
